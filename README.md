# ClassPulse

授業で使う、スライドとアンケートのアプリです。
先生がスライドを映すと、生徒は自分の iPad から、その場でアンケートに答えたり、文章や短い言葉を書いて送ったりできます。
生徒はログインしません。回答に名前は付きません（匿名です）。

- 公開版の URL: https://schooldatahuruyama-lgtm.github.io/classpulse/
- 接続確認ページ: https://schooldatahuruyama-lgtm.github.io/classpulse/check.html

## 授業の流れ

### 先生

1. ログインします（メールアドレスとパスワード、または「Google でログイン」）。
2. 「＋ 新規作成」で教材を作ります。
2'. すでにある資料を使うときは、「PDF から作る」で PDF を選びます。1 ページが 1 枚のスライドになります（ページの見た目を、そのまま 1 枚の画像として貼ります）。PowerPoint や Google スライドの資料は、PDF に書き出してから選びます。取込みが終わるまで、画面は開いたままにしてください。
3. スライドを足します。「資料スライド」には文字・画像・図形を置けます。図形は、四角形・円・三角形・線・矢印の 5 種類です。塗りの色・線の色・線の太さを選べます。線と矢印は、向きと矢印の先も選べます。「いちばん前へ」「いちばん後ろへ」で、重なりの順番を変えられます。「アンケート」には質問と選択肢（2〜6 個）を書きます。「自由記述」と「ワードクラウド」には質問だけを書きます。「クイズ」には質問と選択肢を書き、正解を 1 つ選びます。「5 段階評価」には質問と、両はしの言葉（たとえば「むずかしい」と「かんたん」）を書きます。「動画」には YouTube の URL を貼ります（「ここで再生して確かめる」で、再生できるかを試せます）。入力は自動で保存されます。
4. 「発表を開始」を押します。QR コードとリンクが出ます。教室のスクリーンに映します。
5. 生徒が参加すると、人数が増えます。
6. 「次へ」で進めます。アンケートのスライドに来ると、受付が始まります。回答の人数が増えていきます。
7. 結果の出し方は、アンケートごとに編集画面で選びます。
   - 「先生が表示するまで出さない」: 「結果を表示」を押すと、結果が画面に出ます。生徒の画面にも出ます。押すまでは、結果は誰にも見えません。「結果をかくす」で、また見えなくなります。
   - 「すぐ表示」: ボタンを押さなくても、受付が始まったときから、結果が発表の画面と生徒の画面に出ます。回答が入るたびに数字が変わります。「結果をかくす」で見えなくできます。
7'. 自由記述のスライドでは、生徒が書いている間は件数だけが出ます。「結果を表示」を押すと、集まった文章が一覧で出ます（教室の画面に全員の文章が映ります）。文章をタップすると、その 1 件が大きく表示されます。「かくす」を押すと、その回答は画面から消えます（授業中は元に戻せません。授業履歴では読めます）。生徒の画面には、ほかの人の文章は出ません。
7''. ワードクラウドのスライドでは、生徒が書いている間は人数だけが出ます。「結果を表示」を押すと、集まった言葉が出ます。多くの人が書いた言葉ほど、大きく出ます（全角・半角や、大文字・小文字のちがいは同じ言葉として数えます）。言葉をタップすると、人数と「かくす」が出ます。「かくす」を押すと、その言葉は画面から消えます（授業中は元に戻せません）。
7''-2. 自由記述とワードクラウドでは、悪口などの言葉が入った回答を、自動で止めて画面に出しません（不適切な言葉の自動チェック）。止めた回答があると「確認待ち 2 件」と数だけが出ます。何もしなければ、その回答は教室に映りません。映したいときは、結果を表示している間に「確かめる」→「出す」を押すと、確認待ちの一覧が出ます（この一覧は教室にも映ります。映したくないときは、先に iPad の画面の共有を止めてください）。1 件ずつ「映す」を押すと、その回答が画面に出ます。生徒が書き直すと、もう一度チェックされます。止めた回答は、授業のあとに「授業履歴」と CSV で読めます。生徒の画面には、止めたことは出ません。
7''-3. 動画のスライドでは、発表の画面に YouTube のプレーヤーが出ます。再生は、先生がプレーヤーをタップして始めます。次のスライドへ進むと止まります。生徒の画面には「動画は、前の画面で見てください。」と出ます（生徒の端末では再生しません）。
7'''. クイズのスライドでは、生徒が答えている間は人数だけが出ます。「正解を表示」を押すと、その時点で締め切りになり、選択肢ごとの人数・正解・正答率が出ます。生徒の画面にも、正解と、自分の答えが合っていたかどうかが出ます。正解は、表示するまで生徒の端末には届きません。「正解をかくす」で見えなくできます（締め切りのままです）。
7''''. 5 段階評価のスライドは、アンケートと同じ動きです。結果は、1〜5 それぞれの人数と、平均が出ます。
8. 次のスライドへ進むと、その質問は締め切られます。
9. 最後に「授業を終了」を押します。
10. 「授業履歴」で、質問ごとの結果（選択肢ごとの人数と割合、自由記述の文章、ワードクラウドの言葉と人数、クイズの正答率、評価の平均）を見られます。
12. 授業の結果の画面で「CSV をダウンロード」を押すと、結果を表のファイル（CSV）として端末に保存できます。「Google ドライブに保存」を押すと、Google の画面で許可したあと、結果が Google スプレッドシートとして自分の Drive に作られ、開くためのリンクが出ます。
11. 教材の一覧で「削除」を押すと、教材はゴミ箱に移ります。左のメニューの「ゴミ箱」を開くと、「元に戻す」で一覧に戻せます。ゴミ箱に入れてから 30 日たつと、自動で完全に削除されます。「完全に削除」「ゴミ箱を空にする」で、すぐに消すこともできます（元に戻せません）。

### 生徒

1. 先生が映した QR コードを読むか、リンクを開きます。
2. 先生がスライドを進めると、自分の画面も進みます。
3. アンケートが出たら、選択肢を押して「回答を送信」を押します。
3'. 自由記述が出たら、文章を書いて「送信」を押します（200 文字まで）。
3''. ワードクラウドが出たら、言葉を 3 つまで書いて「送信」を押します（1 つ 20 文字まで。1 つだけでも送れます）。
3'''. クイズと 5 段階評価は、アンケートと同じように、選んで「回答を送信」を押します。
4. 締め切られるまでは、答えを変えられます（自由記述は、書き直して「送り直す」を押します）。
5. 授業が終わると、終了の画面になります。

## まだできないこと

- 正解が 2 つ以上あるクイズ、点数や順位、5 段階以外の評価。名前を付ける回答。先生だけが先に全部の回答を読んで承認すること（iPad が教室に映っているため。代わりに、不適切な言葉の自動チェックがあります）。
- PowerPoint の図形・表・グラフ・背景・アニメーションを取りこむこと（「PowerPoint から作る」で取りこむのは文字と画像だけです）。古い形式（.ppt）や Google スライドを直接読むこと（Google スライドは「ファイル → ダウンロード → Microsoft PowerPoint (.pptx)」で保存すれば取りこめます）。PDF から取りこんだページの文字を打ち直すこと。
- PDF や Excel の形式での出力（CSV とスプレッドシートは出せます）。すべての授業をまとめて書き出すこと。Drive の中のファイルをアプリの中から選ぶこと（Drive にある PDF は、「PDF から作る」のファイルを選ぶ画面から選べます）。教材の控えを Drive に取ること。授業の記録のゴミ箱（授業の記録は、削除するとすぐに消えます）。
- 動画・音声のファイルを載せること、YouTube 以外の動画、生徒の端末での動画の再生、アニメーション。手書きの線、図形の回転、図形の中の文字（文字は、図形の上に文字を重ねて置きます）。
- 管理者をアプリの中で増やすこと。パスワードを忘れたときの再設定（Firebase の画面で行います）。先生どうしで教材を見せ合うこと。
- 200 人が同時に答える使い方。

## 知っておくこと

- 同時につながれるのは 100 台までです（Firebase の無料の枠）。30 人の学級 1 つなら足ります。同じ時間に 3 学級以上で使うと足りなくなります。
- 画像は 1 つの教材で合計 5MB までです。画像はデータベースの中に入れています。
- PDF は 30 ページまで、ファイルは 50MB までです。パスワードの付いた PDF は取り込めません。PDF のファイルそのものは、端末の外へ送りません（画像に変えたものだけを保存します）。
- PDF から作った教材はデータが大きくなります。上限いっぱい（5MB）の教材を 30 人で使うと、1 回の授業で約 150MB を受け取ります。Firebase の無料の枠は 1 か月 10GB までなので、そのような教材なら 1 か月におよそ 60 回の授業が目安です。
- 自由記述の文章とワードクラウドの言葉には名前が付きません。だれが書いたかは、先生にも分かりません。
- 不適切な言葉の自動チェックは目安です。一覧に無い言い方や、わざと文字を変えた書き方は止められません。ふつうの言葉の一部が当たって止まることもあります（例: 「バカンス」）。上の「止める言葉」の画面で、止める言葉を足すこと（100 語まで）と、自動チェックを使わない設定ができます。設定は、次に発表の画面を開いたときから使われます。
- ゴミ箱の教材が自動で消えるのは、30 日たったあとに先生がアプリ（ホームかゴミ箱）を開いたときです。ゴミ箱の中の教材は、編集も発表もできません（元に戻してから使います）。教材を消しても、その教材を使った授業の記録は残ります。
- 「Google ドライブに保存」でアプリがさわれるのは、このアプリが作ったファイルだけです。Drive のほかのファイルは、見ることも変えることもできません。保存したスプレッドシートには、生徒の書いた文章が入ります（名前は付きません）。作ったときは、先生だけが見られます。同じ授業を 2 回保存すると、2 つできます。学校や自治体のアカウントで止められるときは、CSV のダウンロードを使ってください。
- 動画は YouTube だけです。学校のネットワークで YouTube が止められていると再生できません。授業の前に、教室のネットワークで、編集の画面の「ここで再生して確かめる」を試してください。持ち主がほかのサイトでの再生を止めている動画は使えません。広告や関連する動画が出ることがあります。動画を出している間、先生の端末は YouTube（Google）と通信します。
- 資料の取りこみ方は 2 つあります。「PDF から作る」は、1 ページが 1 枚の画像になり、見た目は元のままですが、文字は直せません。「PowerPoint から作る」は、文字と画像を、あとから直せる形で取りこみますが、配置や文字の大きさは元と同じになりません（文字の大きさは 4 段階、色は 6 色になります）。取りこめなかったものは、終わったときに数が出ます。100 枚、50MB までです。PowerPoint のファイルは、端末の外へ送りません。
- アプリを新しくしたあとは、先生の端末も生徒の端末も、一度ページを読み直してください。
- 締め切ったあとに届いた回答は、数えません。
- 授業が終わるときに、送れたかどうかがわからなかった回答があると、生徒の終了の画面に「授業が終わったため、送信できたか確認できなかった回答が N 件あります。」と出ます（終わった授業を開き直したときも出ます）。
- 授業を終了し忘れると、参加のリンクが使えるままになります。授業のあとは必ず「授業を終了」を押してください。
- 通信が切れると、画面に「接続が切れています」と出ます。つながり直すと、続きから使えます。
- 先生がパスワードを Claude Code に伝える必要はありません。パスワードはこのリポジトリのどこにも書きません。

## 先生を増やすには

1. 新しい先生が、ログイン画面の「はじめて使う先生はこちら」から、自分のメールアドレスとパスワード（8 文字以上）で登録します。登録しただけでは、まだ使えません。
2. 管理者の先生が、左のメニューの「先生の管理」を開き、「承認待ち」に出たメールアドレスを、本人に確かめてから「承認する」を押します。
3. 新しい先生が「もう一度確かめる」を押すか、ログインし直すと、使えるようになります。

- 「先生の管理」では、先生ごとに「利用を停止」「再開」もできます。停止しても、教材と授業の記録は消えません。授業の最中の先生を停止すると、その授業は続けられなくなります。
- 登録の入口はだれでも開けるので、知らないメールアドレスが承認待ちに並ぶことがあります。そのときは「ことわる」を押します。メールアドレスが本人のものかどうかは、アプリでは確かめません。承認の前に、本人に声をかけてください。
- 承認された先生が見られるのは、自分の教材と自分の授業の記録だけです。管理者も、ほかの先生の教材は見られません。
- 新しい先生は、「Google でログイン」でも登録できます。Google ではじめて入った人には「まだ登録されていません」と出るので、「利用を申しこむ」を押してもらい、管理者が承認します。
- Google のログインでアプリが受け取るのは、メールアドレスだけです。今のログインと同じメールアドレスの Google アカウントで入ると、同じ先生として入れます。そのあと、パスワードでのログインが使えなくなることがあります（その場合は、Google でログインします）。学校や自治体のアカウントは、管理している人の設定によって、Google の画面で止められることがあります。
- 管理者の登録（最初の 1 回）は、`docs/firebase/setup.md` の「管理者を登録する」の手順で行います。

## 開発者向け

### テスト

```
npm test
```

Node.js 組み込みのテストランナー（`node --test`）で `tests/*.test.js` を実行します。依存パッケージはありません。ビルドもありません。

### 手元で開く

```
python -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/` を開きます（本物の Firebase の設定が `js/firebase-config.js` に入っている場合）。

### 練習モード

`http://127.0.0.1:8765/?demo=1` を開くと、データをそのパソコンの中（localStorage）に置く練習モードになります。どんなメールアドレスとパスワードでもログインできます（メールアドレスごとに別の先生になります。`a@b.c` が、最初から登録されている管理者の先生です。ほかのメールアドレスは、承認待ちから始まります）。生徒はタブを増やして試します（タブごとに別の生徒です）。`localhost`・`127.0.0.1`・`[::1]` 以外では `?demo=1` は無視されます。練習モードは、2 つのタブが同じ瞬間に書きこむ場合を守りません。また、保存できる量が小さく（多くのブラウザで 5MB 前後）、いっぱいになると保存に失敗します。大きい PDF は練習モードでは保存できないことがあります。

### 公開の手順

公開用の `pages` ブランチには、アプリに必要なファイル（`index.html`、`check.html`、`css`、`js`、`assets`）だけを入れます。

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools/pages-branch.ps1
git push origin master
git push origin pages
```

初めてのときは、GitHub の Settings → Pages で、Branch を `pages` / (root) にします。公開する前に、先生が `docs/firebase/setup.md` を終えて、`js/firebase-config.js` に値を入れておく必要があります。
