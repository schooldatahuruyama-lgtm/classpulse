# 図形の追加 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** スライドの要素に `kind: 'shape'`（四角形・円・三角形・線・矢印）を足し、編集・発表・生徒の画面で同じ見た目に出す。

**Architecture:** 今ある要素（`text`・`image`）と同じ箱（x, y, w, h）のしくみに乗せる。要素の作成・正し方・重なりの順番は `js/model.js` の純粋な関数、描画は `js/slide-render.js` の SVG、編集は今のキャンバスと設定の部品に足す。データベースの構造と規則は変えない。

**Tech Stack:** ビルドなしの HTML/CSS/JS（ES modules）、SVG、`node --test "tests/*.test.js"`。

**Spec:** `docs/superpowers/specs/2026-11-13-shapes-design.md`

## Global Constraints

- 作業の決まりは `CLAUDE.md` と `AGENTS.md` に従う。コミットは指揮役が行う。実装する人は commit しない。
- `docs/firebase/rules.json`、`js/session-*.js`、`js/outbox.js`、`js/net.js` を変えない。
- 項目の名前と値は設計書 4 章のとおり（`kind:'shape'`、`shape`、`fill`、`stroke`、`strokeWidth`、`dir`、`head`）。
- 図形の無い今ある教材の見た目・保存される形・動きを変えない。今あるテスト（546 件）を壊さない。
- 編集画面の保存のしくみ（自動保存、裏の保存、削除の見張り）を変えない。図形の変更も、文字や画像の変更と同じ道で保存する。
- SVG は `createElementNS` で組み立てる（文字列から HTML を作らない）。色は、決まった一覧にある値だけを使う（保存されていた値をそのまま属性に入れない。正してから使う）。
- 色だけで状態を伝えない（選んでいる色・「なし」には、色以外の印と名前）。画面の文は今の言い回しにそろえる。

## Review Focus

1. 図形の無い教材・PDF から作った教材・質問のスライドが、今までどおりに見える・保存される。
2. 教材に入っていた不正な値（知らない `shape`、色でない文字列、`<script>` のような文字列）が、画面をこわしたり、そのまま属性になったりしない。
3. 縮小表示・編集・発表・生徒の 4 つの画面で、図形の位置・大きさ・線の太さの比が同じ。
4. 細い線や小さい図形を、指で選べる・動かせる。文字の入力が始まらない。
5. 重なりの順番を変えたあと、複製・削除・保存・読み直しをしても順番が保たれる。

### Task 1: 図形の要素（データ・描画・編集）

**Files:**
- Modify: `js/config.js`, `js/model.js`, `js/slide-render.js`, `js/views/editor.js`, `js/views/editor/canvas.js`, `js/views/editor/inspector.js`, `css/slide.css`, `css/editor.css`
- Test: `tests/model.test.js`、必要なら新しい `tests/shape.test.js`

**Interfaces（Produces）:**
- `CONFIG.shape = { colors: [{ name, value }...], defaultFill, defaultStroke, widths: { s, m, l } }`
- `js/model.js`:
  - `createShapeItem(id, shape)` → 設計書 4 章の形（種類に合う項目だけを持つ。既定値つき）
  - `normalizeShapeItem(item)` → 正した要素。知らない `shape` は `'rect'`、決まった色に無い値は既定の色（`'none'` は残す）、塗りも線も `'none'` なら線を既定の色に、知らない `strokeWidth`・`dir`・`head` は既定値、種類に合わない項目は落とす。箱は `clampItem` と同じ
  - `normalizeDeck` が、`kind:'shape'` の要素を `normalizeShapeItem` に通す（`text`・`image` の扱いは変えない）
  - `bringToFront(slide, itemId)` / `sendToBack(slide, itemId)` → 新しいスライド（`items` の並びを変える。見つからなければ元のまま）
  - `shapeGeometry(item)` → 描くための、箱を 0〜1 とした座標（線の始点と終点、三角形の頂点など）。純粋な関数
- `js/slide-render.js`: `kind:'shape'` を SVG で描く。今ある `renderSlide` の呼び方は変えない
