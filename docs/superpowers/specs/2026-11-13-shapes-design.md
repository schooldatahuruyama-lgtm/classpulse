## 1. 目的

編集画面で、文字や画像と同じように図形を置けるようにする。枠で囲む、矢印で指す、色の帯を文字の下に敷く、といった使い方ができる。

## 2. 入れるもの・入れないもの

### 入れるもの

- 図形の種類: 四角形、円（だ円）、三角形、線、矢印。
- 文字や画像と同じ操作: 置く、動かす、大きさを変える、複製、削除、元に戻す（今あるしくみの範囲で）。
- 色: 塗りの色、線の色（それぞれ「なし」を選べる）、線の太さ（細い・ふつう・太い）。色は決まった色の中から選ぶ。
- 線と矢印: 向き（よこ・たて・ななめ ＼・ななめ ／）、矢印の先（線は「なし」。矢印は「終わり」「始め」「両方」）。
- 重なりの順番: 「いちばん前へ」「いちばん後ろへ」（図形だけでなく、文字と画像にも使える）。
- 発表画面・生徒の画面・縮小表示に、同じ見た目で出る。

### 入れないもの

- 手書き（自由な線）、多角形、星、吹き出し。
- 図形の中の文字（文字は、文字の要素を上に重ねて置く）。
- 回転、影、グラデーション、すきとおり具合。好きな色を作ること。
- 図形どうしをまとめる（グループ）、そろえる、等間隔にする。

### してはいけないこと

- 今ある教材（図形の無いもの）の見た目や動きを変える。
- Firebase の規則やデータベースの構造を変える（教材の中の要素が 1 種類増えるだけ）。

## 3. 画面

- 図形を置けるのは、今、文字や画像を置けるスライドと同じ。
- 「図形」のボタンを押すと、種類を選ぶ小さな一覧が出る。選ぶと、スライドの中央あたりに、決まった大きさで置かれ、選んだ状態になる。
- 図形を選ぶと、右の設定に、その図形で変えられるものだけが出る。
  - 四角形・円・三角形: 塗りの色、線の色、線の太さ。
  - 線: 線の色、線の太さ、向き。
  - 矢印: 線の色、線の太さ、向き、矢印の先。
- 色の選び方は、色のついた丸いボタンを並べる。色の名前を文字でも持つ（読み上げ・色の見分けにくい人のため）。「なし」は、ななめの線が入った丸。選んでいる色には、色以外の印（枠や印）も付ける。
- 図形をダブルタップしても、文字の入力は始まらない。
- 塗りも線も「なし」の図形は見えなくなるので、両方「なし」にはできない（片方を「なし」にしたら、もう片方の「なし」は選べない）。

## 4. データ

```
slides/<スライドID>/items[]:
  { id, kind:"shape", shape:"rect"|"ellipse"|"triangle"|"line"|"arrow",
    x, y, w, h,                      … 今ある要素と同じ（スライドに対する割合）
    fill:   色（"#RRGGBB"）か "none",   … rect・ellipse・triangle だけ
    stroke: 色か "none",
    strokeWidth: "s"|"m"|"l",
    dir:  "h"|"v"|"d1"|"d2",          … line・arrow だけ。h=よこ、v=たて、d1=左上から右下、d2=左下から右上
    head: "end"|"start"|"both" }      … arrow だけ
```

- 色は、`js/config.js` に並べた決まった色（`CONFIG.shape.colors`: 名前と色の組）から選ぶ。保存するのは色の値（文字の要素の `color` と同じ持ち方）。読むときに、決まった色に無い値は既定の色に正す。
- 線と矢印も、箱（x, y, w, h）で持つ。よこの線は箱の高さの中央、たての線は箱の幅の中央を通る。ななめの線は箱の対角を結ぶ。
- 「始め」「終わり」: よこは左が始め・右が終わり。たては上が始め・下が終わり。ななめは左が始め・右が終わり。
- 重なりの順番は、`items` の並び（あとの方が前）。「いちばん前へ」は最後に、「いちばん後ろへ」は最初に動かす。
- 授業の写し・生徒の端末へは、今ある要素と同じ道で届く。規則は変えない。

## 5. 描き方

- 図形は SVG で描く。箱いっぱいに広がり、箱の縦横比が変わっても線の太さは変わらない（のびない）。
- 線の太さは、スライドの大きさに合わせて変わる（縮小表示では細く、発表画面では太く）。同じスライドは、どの画面でも同じ見た目の比になる。
- 矢印の先は、線の太さに合った大きさの三角。箱をつぶしても形がゆがまない。
- 線の端や線の太さの分が、箱からはみ出して切れないようにする。

## 6. 確かめ方

- 自動テスト: 要素の作成と既定値、読むときの正し方（知らない種類・色・向きの値）、複製、重なりの順番の関数、色の一覧に背景との差が足りない色が無いこと（線の色について）。
- ブラウザ（練習モード）: 5 種類を置く、動かす、大きさを変える、色・太さ・向き・矢印の先を変える、両方「なし」にできない、前後を入れかえる、複製、削除、保存して読み直す、縮小表示、発表画面と生徒の画面で同じに見える。図形の無い今ある教材が変わらない。PDF から作ったスライドの上に図形を置ける。

## 7. 実装する人に任せること

- 色の一覧（`css/base.css` の配色から。白・黒・灰色を足してよい）と既定の色。
- 置いたときの大きさと位置、種類を選ぶ一覧の見た目。
- 線の太さの実際の値。
- SVG の組み立て方（上の 5 章を満たすこと）。
