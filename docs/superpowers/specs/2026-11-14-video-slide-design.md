# 動画スライド（YouTube）の設計書

- 作成日: 2026-11-14
- もとになる設計書: `2026-11-11-classpulse-design.md`（段階 4「動画・音声」）
- 要件定義書の項目: 4.1（41 行）、307 行（再生の開始にタップが必要な場合、読みこみの失敗）

「ユーザーの決定」は先生が決めたこと、「Claude の判断」は Claude Code が決めたことである。

## 1. 目的と前提

- **ユーザーの決定:** 段階 4 では「動画（YouTube の URL を貼る）」と「PowerPoint の直接取りこみ」を作る。アニメーションは作らない。この設計書は動画の分。
- 動画・音声のファイルそのものを載せることは作らない（無料の枠には置き場所が無い。1 教材 5MB まで）。Claude の判断。
- 授業の中で、YouTube の動画を、スライドの 1 枚として教室の画面で再生できるようにする。

## 2. 入れるもの・入れないもの

### 入れるもの

- スライドの種類「動画」。YouTube の URL を 1 つと、題（省略できる）を持つ。
- 編集の画面: URL の入力、読み取れたかどうかの表示、「ここで再生して確かめる」。
- 発表の画面: そのスライドに着いたら、動画のプレーヤーを出す。再生は先生がタップして始める（自動では始めない）。
- 生徒の画面: 動画は出さず、「動画は、前の画面で見てください。」と題を出す。

### 入れないもの（理由つき）

- 生徒の端末での再生（30 台が同時に動画を受け取ると、学校の回線が重くなる。教室の画面で一緒に見る使い方にする）。
- YouTube 以外のサービス、動画・音声のファイル、音声だけのスライド。
- 再生の位置・一時停止を、アプリのボタンで操作すること（プレーヤーの中のボタンを使う）。終わりの時刻の指定。
- 動画のサムネイル画像を出すこと（YouTube への通信が、動画を見せる前に起きるため）。

### してはいけないこと

- 先生が入れた URL を、そのまま `iframe` の `src` やリンクに使う（読み取った動画 ID だけを保存し、URL はアプリが決まった形で組み立てる）。
- YouTube のスクリプト（IFrame API など）を、このアプリのページに読みこむ。外部への通信は、下の形の `iframe` 1 つだけ。
- `iframe` を、スライドの一覧の縮小表示・ホーム・生徒の画面・授業の結果の画面に作る。編集の画面では、先生が「ここで再生して確かめる」を押すまで作らない。
- 自動で再生を始める（`autoplay` を付けない）。
- 規則（`docs/firebase/rules.json`）を変える。

## 3. データ

```
teachers/<uid>/decks/<教材ID>/slides/<スライドID>/
  type: "video"
  videoId: "<YouTube の動画 ID。英数字と - _ の 11 文字。無ければ空文字>"
  start: <始める位置の秒。0 以上 86400 以下の整数。無ければ 0>
  caption: "<題。100 文字まで。無ければ空文字>"
```

- 正すとき（`normalizeSlide`）は、この 4 つだけを残す。`videoId` が形に合わなければ空文字、`start` が合わなければ 0。
- 授業の写し（`sessions/<sid>/deck`）にも、そのまま入る（公開されている動画の ID で、秘密ではない）。`pub/polls` には作らない。回答は無い（今の規則では、このスライドへの回答は書けない）。
- 発表を始める前の確かめ（`validateDeck`）: `videoId` が空の動画スライドがあれば「N 枚目: 動画の URL を入れてください。」
- 授業の結果・CSV には出さない（質問ではない）。

## 4. URL の読み取り（純粋な関数。新しい `js/video.js`）

- `parseYouTubeUrl(text): { videoId, start } | null`
  - 前後の空白を取る。`https://` か `http://` で始まる URL、または `youtu.be/…`・`www.youtube.com/…` のようにスキームの無い形（`https://` を足して読む）。
  - ホストは、`youtube.com`・`www.youtube.com`・`m.youtube.com`・`music.youtube.com`・`youtu.be`・`www.youtube-nocookie.com` だけ（大文字・小文字は区別しない。`youtube.com.example.org`・`notyoutube.com` は読まない）。
  - 形: `/watch?v=ID`、`youtu.be/ID`、`/embed/ID`、`/shorts/ID`、`/live/ID`。
  - 動画 ID は `^[A-Za-z0-9_-]{11}$` に合うものだけ。
  - 始める位置: `t` か `start` の値。`90`・`90s`・`1m30s`・`1h2m3s` を秒にする。読めなければ 0。86400 をこえたら 0。
  - 再生リストだけの URL（`/playlist?list=…`）、チャンネルの URL、動画 ID だけの文字列は `null`。
- `youTubeEmbedUrl({ videoId, start }): string | null` … `https://www.youtube-nocookie.com/embed/<ID>?rel=0&playsinline=1`（`start` が 1 以上なら `&start=<秒>`）。`videoId` が形に合わなければ `null`（もう一度ここで確かめる）。
- `youTubeWatchUrl({ videoId, start }): string` … 入力欄に出し直す形 `https://youtu.be/<ID>`（`start` が 1 以上なら `?t=<秒>`）。

## 5. 画面

### 5.1 プレーヤー（`iframe`。作るのは 1 つの関数にまとめる）

- `src` は `youTubeEmbedUrl` の値。`title="YouTube の動画"`（題があれば題）。
- `allow="encrypted-media; picture-in-picture; fullscreen"`、`allowfullscreen`、`referrerpolicy="strict-origin-when-cross-origin"`（YouTube は、参照元が無いと再生をことわることがある）、`sandbox="allow-scripts allow-same-origin allow-presentation"`、`loading="lazy"` は付けない。
- スライドの枠（16:9）いっぱいに置く。題は、プレーヤーの中には出さない（発表の画面では出さない。編集の画面では入力欄にある）。

### 5.2 編集の画面

- スライドを足す所に「＋ 動画」。
- 右の列「動画の設定」: 入力欄「YouTube の URL」、入力欄「題（生徒の画面に出ます。省略できます）」（100 文字まで）。
  - URL を読み取れたら、その下に「動画を読み取りました。」（始める位置があれば「1 分 30 秒から始めます。」も）。
  - 入っているのに読み取れないときは「YouTube の動画の URL を入れてください。」（`role="alert"`）。このとき `videoId` は空文字にする。
  - 開き直したとき、入力欄には `youTubeWatchUrl` の形で出す。
  - 説明: 「動画は、発表の画面（教室の画面）で再生します。生徒の端末では再生しません。学校のネットワークで YouTube が見られないときは、使えません。」
- 中央: 動画の見本（プレーヤーではない。▶ の印、「動画（YouTube）」、題）。その下にボタン「ここで再生して確かめる」（`videoId` があるときだけ押せる）。押すと、見本がプレーヤーに変わる。URL を変えた・別のスライドへ移ったら、見本に戻す。
- スライドの一覧の縮小表示: 見本（▶ の印と「動画」のしるし）。

### 5.3 発表の画面

- 動画スライドに着いたら、中央にプレーヤーを出す。別のスライドへ移ると、プレーヤーは消える（再生も止まる）。
- 回答が届く・参加人数が変わるなどで画面を書きかえるとき、プレーヤーを作り直さない（今の `shownKey` のしくみで、スライドが変わったときだけ作る）。
- 右の欄（アンケートの状況）と、受付・結果のボタンは出さない（資料スライドと同じ）。
- `videoId` が空（古いデータなど）なら、見本と「動画の URL がありません。」を出す。

### 5.4 生徒の画面

- 「動画は、前の画面で見てください。」と、題（あれば）。プレーヤーは作らない。

## 6. 知っている限界

- 学校・自治体のネットワークで YouTube が止められていると、プレーヤーの中にエラーが出る（アプリからは、再生できたかどうかが分からない）。授業の前に、編集の画面の「ここで再生して確かめる」を、教室のネットワークで試す必要がある。
- 動画の持ち主が「ほかのサイトでの再生」を止めている動画・年齢の確認が要る動画・非公開の動画は、再生できない。
- 再生の前後に、YouTube の広告や、関連する動画が出ることがある（`rel=0` でも、同じチャンネルの動画は出る）。
- プレーヤーの中を操作している間は、キーボードの「→」で次へ進めない（画面の「次へ」を押す）。
- 動画を出している間、先生の端末から YouTube（Google）へ通信する。生徒の端末からは通信しない。

## 7. 確かめ方

- 自動テスト: URL の読み取り（読める形・読めない形・似たホスト・始める位置）、組み立てる URL、正し方、発表前の確かめ、授業の組み立て（`pub/polls` に作らない）、履歴に出ない、プレーヤーの属性、生徒の画面と縮小表示に `iframe` が無い、発表の画面で状態が変わってもプレーヤーを作り直さない。
- ブラウザ（練習モード）: 動画スライドを作る → 確かめる → 発表 → プレーヤーが出る → 次へで消える。生徒のタブに `iframe` が無い。
- 本物: 学校のネットワークと iPad での再生は、先生が試す。規則の貼り直しは、いらない。
