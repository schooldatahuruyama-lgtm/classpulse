# 「元に戻す」と「大きさを変えるボタン」の設計書

- 作成日: 2026-11-14
- **ユーザーの決定:** 編集画面に「元に戻す」と「大きさを変えるボタン」を作る。
- **Claude の判断:** この下の作り方すべて（「やり直す」も付ける、戻せる回数、ボタンの場所、まとめ方、歩はば）。

## 1. 元に戻す・やり直す

### 1.1 見え方

- 編集画面の上の帯に、ボタン 2 つ: 「元に戻す」「やり直す」。
  - 幅 900px 以上: 「発表を開始」の左に、文字のボタン「↶ 元に戻す」「↷ やり直す」。
  - 幅 899px 以下: 上の帯の 2 段目（保存の状態の右）に、44×44px の「↶」「↷」（読み上げの名前「元に戻す」「やり直す」）。
- 戻すものが無いときは、押せない（`disabled`）。
- キーボード: Ctrl+Z（Mac は ⌘+Z）で元に戻す。Ctrl+Shift+Z と Ctrl+Y でやり直す。**入力欄（`input`・`textarea`）にフォーカスがある間は、アプリは何もしない**（ブラウザの文字の取り消しにまかせる）。
- 押したあと: 変わった所が見えるように、その変更をしたときのスライドへ切りかえる。読み上げ用に「元に戻しました。」「やり直しました。」を `aria-live` で知らせる（トーストは出さない。連打でうるさくなるため）。

### 1.2 何を戻すか

- 教材の中身の変更すべて（教材名、スライドの追加・削除・複製・並べかえ、要素の追加・削除・移動・大きさ・文字・色など、質問や選択肢、動画、背景）。教材を変える所は、今すべて `change()` を通る。そこで、変える前の教材を覚える。
- 戻すと、ふつうの変更と同じように自動保存される。
- 覚えるのは、教材（今も作り直さない作りなので、前の教材への参照を持つだけ）と、そのときに選んでいたスライド・要素。
- **戻せるのは 50 回まで。** 古いものから捨てる。
- **この画面を開いている間だけ。** 一覧へ戻る・読みこみ直す・発表を開始すると、覚えたものは消える。
- 新しい変更をすると、「やり直す」のぶんは消える。

### 1.3 続けた操作は 1 回にまとめる

- 次のものは、**同じ所への変更が 1 秒以内に続いたら、1 回ぶん**にまとめる（1 文字ずつ戻らないように）:
  - 文字の入力（同じ要素）、教材名、質問文・選択肢などの入力（同じスライドの同じ項目）、「←→↑↓」と大きさのボタン（同じ要素の同じ種類）。
- ドラッグは、指を離したときの 1 回だけが変更なので、そのまま 1 回ぶん。
- 文字の入力を終える（`finishEdit`）・スライドや要素の選択を変える・元に戻す／やり直す、のあとは、まとめを切る（次の変更は新しい 1 回ぶん）。

### 1.4 スライドの削除の確認

- 確認は今のまま出す。文を変える: 「削除したスライドは元に戻せません。」→「この画面を開いている間は、「元に戻す」で戻せます。」

## 2. 大きさを変えるボタン（幅 899px 以下だけ）

- 設定のパネルの「位置を少し動かす」の下に「大きさを少し変える」。文字・画像・図形のどれにも出す。
  - 1 段目: 「大きく」「小さく」（縦と横をいっしょに。形の比を保つ）
  - 2 段目: 「横に広く」「横にせまく」「縦に広く」「縦にせまく」
- 左上の位置は動かさない（今のつまみと同じ）。
- 歩はば: 「大きく」「小さく」は 5%（今の幅・高さに 1.05 を掛ける／割る）。2 段目は、スライドの幅・高さの 2%。
- 止まる所: 右と下はスライドの端、小さいほうは今の最小（`MIN_ITEM_SIZE`）。「大きく」は、縦か横のどちらかが端に当たる所まで（比を保ったまま止まる）。「小さく」は、どちらかが最小になる所まで。止まっても、ボタンは押せるまま（動かないだけ）。
- 幅 900px 以上には出さない（つまみとキーボードの矢印がある）。

## 3. 端の場合

| 場合 | 動き |
|---|---|
| 戻すものが無い・やり直すものが無い | ボタンは押せない。キーも何もしない |
| 51 回目の変更 | いちばん古い 1 回ぶんを捨てる |
| 同じ値への変更（教材が変わらない） | 覚えない（押しても何も起きない 1 回ぶんを作らない） |
| 文字の入力中に「元に戻す」 | 入力を終えてから戻す |
| 戻した先に、今選んでいるスライド・要素が無い | 覚えていたスライドを選ぶ。それも無ければ近いスライド。要素の選択は外す |
| 画像を消す → 元に戻す | 画像も戻る（前の教材が画像を持っている） |
| 画像の読みこみ中（縮めている間）に元に戻した | 読みこみが終わると、今の教材に足される（ふつうの変更として 1 回ぶん）。元のスライドがもう無ければ、今の「足せませんでした」の文 |
| 発表の準備中・教材が削除済み・保存に失敗中 | 準備中と削除済みは押せない。保存に失敗中は押せる（戻したものを、次の保存で書く） |
| 連打・キーの押しっぱなし | 1 回ごとに 1 歩。こわれない |
| 入力欄にフォーカスがあるときの Ctrl+Z | アプリは何もしない |
| 確認の窓（ダイアログ）が開いているときの Ctrl+Z | 何もしない |
| 別のタブで同じ教材を変えた | 今までと同じ（このタブの保存があとから上書きする）。この機能では変えない |
| 大きさのボタン: 端・最小・不正な値（数でない・はみ出している） | `clampItem` で正してから計算。端と最小で止まる。知らない種類は元のまま |
| 大きさのボタン: 線・矢印（細い図形） | ほかと同じ計算。最小より小さくならない |

## 4. やらないこと

- 画面を離れたあとも戻せるようにする、ほかの端末と履歴を合わせる、操作の一覧を見せる。

## 5. 確かめ方

- 自動テスト: 履歴の入れ物（積む・戻す・やり直す・50 回・まとめ・同じ値は覚えない）、戻したあとの選択、大きさの計算（端・最小・比）、キーの判定（入力欄では何もしない）。
- ブラウザ（練習モード、幅 375px と 1280px）: 要素を動かす・消す・スライドを消す → 元に戻す → やり直す。文字を打つ → 1 回で戻る。大きさのボタン。
