## Claude Code の確認で見つけて、Codex が直したこと

- **`sw.js` が、ページの移動を `fetch(request, { cache: 'no-cache' })` で取っていた。** `navigate` の要求に `init` を付けると例外になるブラウザがあり、そのとき「通信がつながっているのに、2 回目からページが開けない」ことになりえた（自動テストは偽の `fetch` なので気づけない）。ページの移動は URL から取り直し、例外のときは `init` なしでもう 1 回試してから、キャッシュへ進むようにした。
- はじめての端末で、Service Worker が効く前に読みこんだ部品がキャッシュに入らなかった。効きはじめたら、読みこんである部品を 4 個ずつ取り直して入れるようにした。
- 参加のやり直しで、参加の書きこみの失敗（規則の拒否もふくむ）がエラーの画面になり、やり直しのたびに教材の写し（最大 5MB）を取り直していた。前の動き（書きこみの失敗は無視して進み、つながったときにもう一度試す）に戻し、読めた教材は取り直さないようにした。

## 数字の見つもり（30 人の学級 1 つ）

- **同時接続:** 生徒 30 ＋ 先生 2 ＝ 32。無料の枠は 100（Firebase の資料: Spark は 100）。同じ時刻に 3 学級（96）までは収まる計算だが、余りが 4 しか無い。REST の受信が同時接続に数えられるかは、資料に書かれていない（数えられるとみている）。
- **アカウント作成:** Firebase の資料は「新しいアカウントの作成は、1 つの IP アドレスから 1 時間に 100 まで」。生徒は、はじめて使う端末（ブラウザ）で 1 回だけ匿名のアカウントを作り、端末に残す。次の授業からは作らない。
  - 学校は 1 つの IP アドレスにまとまることが多い。**はじめて使う日に、同じ 1 時間のうちに 4 学級（120 人）以上が使うと、上限をこえて、あとの生徒が参加できないおそれがある。**（匿名の作成がこの数に入るかは、資料に書かれていない。入るとみて備える。）
  - 対処: (a) はじめて使う日は、1 時間に 3 学級までにする。(b) Firebase の画面（Authentication → 設定 → 登録の割り当て）で、日時を決めて一時的に枠を広げる。
  - プライベートブラウズ（履歴を残さない窓）や、端末のデータを消す設定の学校では、毎回アカウントを作ることになる。そのときは、毎時間この上限がかかる。
- **通信量:** 参加のとき、生徒 1 人が教材の写しを 1 回受け取る（PDF から作った上限いっぱいの教材なら約 5MB × 30 人 ＝ 約 150MB。README のとおり）。授業中の変化は、生徒 1 人あたり数千文字ほど。
- **戻ったときのつなぎ直し:** つなぎ直すたびに、生徒は `pub`（小さい）、先生は回答の箱（30 人分）を受け取り直す。教材の写しは受け取り直さない。

## 確かめたこと

### 練習モード（内蔵のブラウザ）

- 今までの流れが動く。存在しない授業の参加の画面は、今までどおり「この授業は見つかりません。」。コンソールにエラーが無い。`localhost` では Service Worker を登録しない。

### Service Worker（このパソコンの Edge を、空の設定・画面なしで動かして確かめた。`127.0.0.1` に手で登録）

- 登録できる。登録のあとページが受け持たれる。
- 受け持たれた状態で読みこみ直しても、ページが開く（ページの移動がネットワークから取れる）。部品が 30 個キャッシュに入る。
- サーバーを止めてから読みこみ直しても、アプリの画面（ログインの画面）が出る。キャッシュに無い部品は、ふつうに失敗する。

### 公開先（2026-11-14 公開。pages 44ef1a7）

- `sw.js` が公開先の一番上に出ている（HTTP 200、`application/javascript`）。公開先の `js/main.js` に登録の処理が入っている。
- **公開先のページをブラウザで開いての確認は、できていない。** Claude Code が公開先を自動で開く操作（画面なしの Edge・内蔵のブラウザの両方）は、権限の設定で止められた。回り道はしていない。先生に、下の「公開先で先生に見てほしいこと」をお願いする。

## 作らなかったもの（理由）

- 締切のあとに届いた回答を数えること（端末の時刻は信用できず、締切の前に書いたと確かめる方法が無い）。
- 本物の Firebase に対して機械で 30 人分の参加を作る道具（アカウント作成の上限を試験で使ってしまう）。
- 200 人への対応。先生の端末が切れている間の操作をためておくこと。
