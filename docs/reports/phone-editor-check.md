## 変わったこと（幅 899px 以下だけ）

- 上の帯が 1 段＋保存の状態（高さ 210px → 99px）。キャンバスの幅 311px → 327px。
- 下に固定の帯「スライド（1／2 枚）」「設定」。押すと下からパネル（画面の高さの 45% まで）。
- 要素を選ぶと、キャンバスの下に「文字を入力」「設定」「選択を外す」。
- 文字は、キャンバスの上の入力欄（18px）で入れる。入力中は下の帯を隠す。
- 指とペンは「選んでから動かす」。選んでいない要素の上からは、画面を送れる。
- 設定に「要素を選ぶ」の一覧と、「←→↑↓」で少し動かすボタン。
- 資料以外のスライドは、設定を中央の下にいつも出す。選択肢の入力欄は 1 行いっぱい。

## ブラウザで確かめたこと（練習モード、Claude Code）

- 幅 375×812: 上の帯 99px、キャンバス 327px、横にはみ出さない。押せるものはすべて 44px 以上、入力欄はすべて 16px 以上。
- 指のタップ（`pointerType: touch`）で要素を選ぶ → すぐ使うボタンが出る。
- 「文字を入力」→ 入力欄が出て、下の帯が隠れる → 打つとキャンバスに映る（入力欄は作り直されない）→「できた」でフォーカスが「文字を入力」へ戻る。
- 「設定」→ パネルが開き、見出しにフォーカス。一覧に、入れた文字の抜粋が出る。「右へ」で 10% → 11%。
- 「スライド」→「＋ スライドを追加」が開閉する → クイズを足すとパネルが閉じ、「スライド（2／3 枚）」になり、「設定」が消えて設定が中央の下に出る。
- 幅 1280×800: 3 列（200px・中央・280px）、並びは今までどおり、下の帯・パネルの見出し・スマホ用の部品は出ない。
- コンソールにエラーなし。
