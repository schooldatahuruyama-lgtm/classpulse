### 確かめたこと（練習モード。Claude Code のパソコンのネットワーク）

- 編集の画面: 「＋ 動画」で動画スライドができる。YouTube でないホストの URL は「YouTube の動画の URL を入れてください。」になり、「ここで再生して確かめる」を押せない。YouTube の URL（`&t=1m5s` つき）は「動画を読み取りました。1 分 5 秒から始めます。」になる。
- ボタンを押す前は、画面に `iframe` が無い。押すとプレーヤーが出て、タップで再生できた（`sandbox` を付けたままで再生できる）。
- 発表の画面: 動画スライドに着くとプレーヤーが出る。生徒が参加して人数が変わっても、プレーヤーは作り直されない。次のスライドへ進むと消える。
- 生徒の画面: 「動画は、前の画面で見てください。」と題だけが出て、`iframe` は無い。
- コンソールにエラーが無い。

### 確かめていないこと

- 学校のネットワーク、iPad（Safari）での再生。全画面の表示。
- 再生できない動画（ほかのサイトでの再生を止めている動画など）を入れたときの見え方。

### 分かっていること

- アプリからは、再生できたかどうかが分からない（プレーヤーの中にエラーが出るだけ）。
- 動画の長さより後ろの「始める位置」を入れても、エラーにはしない（YouTube の動きに任せる）。
- 編集の画面で、プレーヤーと「ここで再生して確かめる」の間のすきまがせまい（見た目だけ）。
