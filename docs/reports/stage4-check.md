### 確かめたこと（練習モード。確認用の .pptx は Claude Code が手で組み立てたもの）

- 「PowerPoint から作る」で教材ができる。題（レイアウトから位置を受けつぐ）・本文（赤い文字、改行）・画像・グループの中の文字が、編集できる要素として入る。

- まとめ: 「2 枚のスライドを取りこみました。…」「取りこめなかったもの: 図形 1、表・グラフ 1、画像 1、非表示のスライド 1」（外部を指す画像は「画像」に数えられ、読みに行かない）。

### ブラウザで確かめたこと（練習モード、Claude Code）

- 編集: 文字 3 つに順番 0・1・3 を付ける → キャンバスの印は「1」「2」（つめた後）。図形に順番 5 → 文「順番 5（「次へ」の 3 回目で出る）」。図形の塗りの色を変えても、順番が残る。
- 発表: 来たときは順番のある 2 つが隠れ、「出す 0／2」。「次へ」で 1 つずつ出る（出る要素にだけフェードの印）。全部出ると「次へ」が最後の表示に変わる。「前へ」で 1 つずつ隠れる。0 のときの「前へ」は何も起きない（1 枚目のため）。
- 開始前の画面から 1 枚目へ進むと、切り替え効果の印が付く。
- 生徒の画面（同じブラウザの別の枠）: 途中から参加すると、今のところまでがフェードなしで出る。先生の「前へ」「次へ」に合わせて、同じところまで出る・隠れる。
