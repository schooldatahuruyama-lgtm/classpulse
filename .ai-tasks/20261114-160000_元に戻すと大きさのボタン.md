# 実装指示書: 「元に戻す」「やり直す」と、大きさを変えるボタン

**設計書（全部読むこと。これが正）:** `docs/superpowers/specs/2026-11-14-undo-resize-design.md`
**関係する設計書:** `docs/superpowers/specs/2026-11-14-editor-phone-design.md`（せまい画面の作り）

## 守ること

- 変えてよいのは: `js/views/editor.js`、`js/views/editor/canvas.js`、`js/views/editor/inspector.js`、`js/views/editor/phone-logic.js`、新しい `js/views/editor/history.js`（DOM に触れない）、`css/editor.css`、`tests/` の新しいテスト（今あるテストは、文言の変更で直しが要るものだけ）。ほかを変える必要が出たら、変えずに報告に書く。
- git の操作はしない。パッケージを足さない。データの形と保存のしかたは変えない。
- 文言は設計書のとおり。押せるものは、せまい画面で 44×44px 以上。

## 作るもの

1. `js/views/editor/history.js`（新規。DOM に触れない）: `createHistory({ limit = 50, groupMs = 1000, now = Date.now })` → `{ record(snapshot, groupKey), undo(current), redo(current), canUndo(), canRedo(), breakGroup(), clear() }`。
   - `record(snapshot, groupKey)`: 変える**前**の `{ deck, slideId, itemId }` を積む。`groupKey` が文字で、直前の記録と同じ鍵で、`groupMs` 以内なら、積まない（時刻だけ更新）。やり直しのぶんを消す。
   - `undo(current)` / `redo(current)`: 今の状態を反対側へ積み、戻す先の状態を返す。無ければ `null`。まとめを切る。
2. `js/views/editor.js`: `change(next, parts, { group } = {})` で、`next !== state.deck` のときだけ記録する。`ed.undo()`・`ed.redo()`（入力を終える → 状態を戻す → 選択を直す → 自動保存 → 一覧・中央・右を描き直す）。上の帯のボタン、`aria-live` の知らせ、キーボード、押せる・押せないの更新、スライド削除の確認の文。まとめの鍵は、設計書 1.3 のとおりに、それぞれの呼び出しから渡す。
3. `js/views/editor/phone-logic.js`: `resize(item, kind)`。`kind` は `'bigger' | 'smaller' | 'wider' | 'narrower' | 'taller' | 'shorter'`。設計書 2 章の計算。知らない `kind` は元のまま。
4. `js/views/editor/inspector.js` と `css/editor.css`: 「大きさを少し変える」（せまい画面だけ）。上の帯のボタンの見た目（幅 900px 以上と 899px 以下）。

## 端の場合（設計書 3 章の表のとおり。全部にテストか、報告での確かめを付ける）

| 場合 | 動き | テスト |
|---|---|---|
| 不正な入力: `record` に `null`、`groupKey` が文字でない、`undo` を空で呼ぶ | 例外にしない。`null` は積まない／まとめない／`null` を返す | 自動 |
| 不正な入力: `resize` に数でない `w`・はみ出した要素・知らない `kind` | `clampItem` で正す／元のまま | 自動 |
| 境界: 50 回と 51 回、`groupMs` ちょうど・1ms こえ | 51 回目で古いものを捨てる。ちょうどはまとめる、こえたら分ける | 自動 |
| 境界: 端・最小での `resize`、「大きく」で片方だけ端 | 止まる。比を保つ | 自動 |
| 重複: 同じ教材で `change`、同じボタンの連打 | 覚えない／1 秒以内は 1 回ぶん | 自動 |
| 新しい変更のあと | やり直せない | 自動 |
| 戻した先に選択が無い | 設計書のとおりに直す | 自動 |
| 文字の入力中・画像の読みこみ中・準備中・削除済み・ダイアログ・入力欄のフォーカス | 設計書のとおり | 自動（できる所）＋報告 |
| 違反や失敗の見せ方 | 新しい失敗の文は無い。押せないときは `disabled`。結果は `aria-live` | 自動 |
