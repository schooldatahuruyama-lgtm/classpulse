# 実装指示書: 動画スライド（YouTube）

**設計書（先に全部読むこと。データの形・画面の文・`iframe` の属性は、設計書のとおりに）:** `docs/superpowers/specs/2026-11-14-video-slide-design.md`

**Goal:** スライドの種類「動画」を足す。先生が YouTube の URL を貼ると、発表の画面でプレーヤー（`iframe`）が出る。生徒の画面には出さない。

**Tech Stack:** ビルドなしの HTML/CSS/JS（ES modules）、`npm test`（今 920 件が通っている）。

## Global Constraints

- 外部のスクリプトを読みこまない。外部への通信は、`https://www.youtube-nocookie.com/embed/…` の `iframe` だけ。`index.html` と CSS に外部 URL を足さない（`tests/static.test.js` を通す）。
- 先生が入れた URL の文字列を、`src`・`href` にそのまま使わない。保存するのは `videoId`・`start`・`caption` だけ。
- `iframe` を作る場所は、発表の画面（今のスライドが動画のとき）と、編集の画面（「ここで再生して確かめる」を押したあと）だけ。`renderSlide` の既定の動きでは作らない（引数で明示したときだけ作る）。
- `docs/firebase/rules.json`、`js/session-host.js`、`js/session-client.js`、`js/outbox.js`、`js/repo.js` を変えない（変えないと作れないと分かったら、最小の変更にして、報告に理由を書く）。
- 今あるコードの書き方に合わせる（日本語のコメント、`el()`、`innerHTML` を使わない）。今あるテストを壊さない。git の操作はしない。パッケージを足さない。

## Review Focus（必ずテストで押さえる）

1. 似たホスト（`youtube.com.example.org`、`notyoutube.com`、`youtu.be.evil.jp`）、`javascript:`・`data:` の URL、ID が 11 文字でない・使えない文字をふくむ URL は `null`。
2. 保存されたデータの `videoId` がこわれている（`"><script>`、`../x`、数、長すぎる）とき、`normalizeSlide` が空文字にし、`youTubeEmbedUrl` も `null` を返す（`iframe` を作らない）。
3. 生徒の画面、スライドの一覧の縮小表示、既定の `renderSlide` に `iframe` が無い。
4. 発表の画面で、同じ動画スライドにいる間に状態が何度変わっても、`iframe` の要素が同じまま（作り直さない）。別のスライドへ移ると消える。
5. 動画スライドがあっても、授業の組み立て・進行（次へ・前へ・締切）・履歴・CSV が今までどおり（`pub/polls` に作らない、履歴の質問に入らない）。

## 作るもの

1. `js/video.js`（新しい）と `tests/video.test.js`: `parseYouTubeUrl`、`youTubeEmbedUrl`、`youTubeWatchUrl`、`VIDEO_ID_PATTERN`、始める位置を「1 分 30 秒」の形にする関数。上限は `CONFIG.video = { captionMaxLength: 100, maxStart: 86400 }`（`js/config.js`）。
2. `js/model.js`: `createSlide('video')`、`normalizeSlide`（設計書 3 章）、`validateDeck`。テスト: `tests/model.test.js`。
3. `js/slide-render.js`・CSS: 動画の見本（`mode: 'thumb'` と既定）、プレーヤー（`renderSlide(…, { player: true })` のように、明示したときだけ）。プレーヤーの `iframe` を作る関数は 1 つにまとめて書き出す。
4. 編集の画面（`js/views/editor.js`、`js/views/editor/inspector.js`、`js/views/editor/slide-list.js`）: 設計書 5.2。
5. 発表の画面（`js/views/present.js`）: 設計書 5.3。
6. 生徒の画面（`js/views/student.js`）: 設計書 5.4（この画面の、動画スライドの表示だけを足す。ほかは変えない）。
7. `js/session-logic.js` は、動画スライドで今のまま正しく動くなら変えない。テストだけ足す（`tests/session-logic.test.js`）。
8. 画面のテストは、今ある `tests/present-view.test.js`・`tests/student-view.test.js` のやり方に合わせて足す。
