## 指示書と違う点・判断したこと・残った問題

- 変更は指定ファイル・新規テストの範囲内です。git 操作、パッケージ追加、保存形式の変更はありません。
- 既存の `change()` を通らない変更は、**画面を離れた後に画像読み込みが完了する処理**にありました。履歴は画面内だけの仕様なので、既存の保存処理を維持しました。undo／redo の復元も、再記録を避けるため直接状態を戻して自動保存します。
- 同じ値でも新しい教材を返す既存関数に対応し、同値の入力や端で止まった操作を履歴に積まない判定を追加しました。
- 記録したスライドが存在しない場合の「近いスライド」は、復元前の選択位置に相当するスライドとし、枚数が減っていれば末尾を選びます。

まとめの鍵は次の呼び出しに付けました。要素の操作にはスライド ID・要素 ID、項目の入力にはスライド ID を組み合わせています。

| 呼び出し | 鍵 |
|---|---|
| 教材名の入力 | `title` |
| キャンバスの文字入力 | `text` |
| 位置のボタン | `nudge:方向` |
| サイズのボタン | `resize:種類` |
| 要素・つまみの矢印キー | `move:キー:歩幅`／`handle:キー:歩幅` |
| 質問文・選択肢 | `question`／`option:番号` |
| 評価の両端の言葉 | `lowLabel`／`highLabel` |
| 動画 URL・題 | `video-url`／`caption` |
