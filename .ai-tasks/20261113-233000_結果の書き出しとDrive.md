# 実装指示書: 授業の結果の書き出し（CSV・Google Drive）

**設計書（先に全部読むこと。CSV の並び・画面の文・しくみは、設計書のとおりに）:** `docs/superpowers/specs/2026-11-13-results-export-drive-design.md`

**Goal:** 授業の結果の画面に「CSV をダウンロード」と「Google ドライブに保存」（スプレッドシートとして作る）を足す。

**Tech Stack:** ビルドなしの HTML/CSS/JS（ES modules）、REST だけ、`npm test`（今 739 件が通っている）。

## Global Constraints

- 外部のスクリプト・スタイルを読みこまない。Google へは、ページの移動と `fetch` だけ。
- アクセストークンを、`localStorage`・`sessionStorage`・URL・履歴・ログ・エラー文に残さない（モジュールの中の変数だけ）。`sessionStorage` に入れるのは `{ state, sid, at }` だけで、戻ってきたらすぐ消す。
- 求める権限は `https://www.googleapis.com/auth/drive.file` だけ。
- `FIREBASE.googleClientId` が空・練習モードのときは、Drive のボタンを出さず、Drive の戻りも処理しない。CSV のダウンロードは、練習モードでも使える。
- 今ある Google ログイン（`js/google-login.js` の `handleGoogleCallback`・`createGoogleLogin`）の動きとテストを壊さない。共通にできる部品（乱数、戻る場所、ハッシュの読み取り）は、今ある関数を使う。
- 今あるコードの書き方に合わせる（日本語のコメント、`el()`、`innerHTML` を使わない、通信・乱数・時計・保存先は引数で受け取ってテストできる形）。
- `js/session-*.js`、`js/outbox.js`、`js/model.js`、`js/repo.js`、`docs/firebase/rules.json`、編集・発表・生徒の画面を変えない。
- git の操作はしない。パッケージを足さない。

## Review Focus（必ずテストで押さえる）

1. 生徒が書いた文章が式にならない: `=1+1`、`+1`、`-1`、`@SUM(A1)`、`  =x`（前に空白）、タブで始まる文章に `'` が付く。人数・割合・平均の数には付かない。
2. `state` が合わない・保存が無い・10 分をこえた戻りでは、トークンを使わない（メモリにも置かない）。
3. ハッシュの置きかえが、ほかのどの処理よりも先（途中で失敗しても、トークンが URL に残らない）。
4. Google ログインの戻り（`#id_token=…`）と、Drive の戻り（`#access_token=…`）を取りちがえない。`#error=…` は、`state` がどちらの保存と合うかで決める。どちらとも合わなければ、今までどおりログインの失敗として扱う。
5. 戻ったあとの自動の保存は 1 回だけ（ページを読みこみ直しても、もう 1 つ作らない）。別の授業の結果の画面では、自動で保存しない。

## 作るもの

### 1. `js/results-csv.js`（新しい。純粋な関数）

- `historyToCsv(history, { bom = false } = {}): string` … 設計書 4 章。
- `csvCell(value): string`（文字の値のエスケープと、式にしない処理）、数を書くときは別の道（そのまま文字にする）。
- `exportFileName(history): string`（拡張子なし。設計書 3 章 4・5 章の決まり。日付は終了の時刻から、端末の時刻で）。
- 割合・正答率・平均の計算は、今ある関数（`js/session-logic.js` の `correctRate`、`average` など）を使えるなら使う。
- テスト: 新しい `tests/results-csv.test.js`。5 種類の質問がまざった履歴の、CSV 全体を文字列で比べるテストを 1 つ入れる。

### 2. `js/drive-export.js`（新しい。ブラウザの物は引数で受け取る）

- `CONFIG.driveExport = { maxAgeMs: 600000, storageKey: 'classpulse:drive-export', scope: 'https://www.googleapis.com/auth/drive.file', tokenMarginMs: 60000 }` を `js/config.js` に足す。
- `buildDriveAuthUrl({ clientId, redirectUri, state, loginHint })`
- `parseDriveCallback(hash): { accessToken, expiresIn, state } | { error, state } | null`
- `createDriveExport(deps)` … `clientId` が空か `demo` なら `null`。それ以外は、次を持つ物を返す（トークンと「戻ったら保存する授業」の印は、この中の変数に置く）:
  - `handleCallback(): { handled: boolean, notice?: string }`（起動時に 1 回。設計書 3 章 3）
  - `hasToken(): boolean`、`takePending(sid): boolean`（その授業の印があれば消して `true`）
  - `begin(sid): void`（`state` を保存して Google へ移る）
  - `upload({ name, csv }): Promise<{ id, webViewLink }>`（設計書 3 章 4。失敗は `NetError` の `code`: `'drive-auth'`（401。トークンを捨てる）、`'drive-denied'`（403）、`'network'`、`'drive-failed'`）。`js/errors.js` の一覧に足す。
  - `deps`: `clientId`、`demo`、`location`、`replaceState`、`sessionStorage`、`fetch`、`now`、`getRandomValues`、`assign`、`getLoginHint`
- `multipart/related` の本文は、境界の文字列を乱数で作り、手で組み立てる（`FormData` は `multipart/form-data` になるので使わない）。
- テスト: 新しい `tests/drive-export.test.js`。

### 3. つなぎこみ（`js/main.js`、`js/views/history.js`、`css/app.css`）

- `main.js`: 起動時、Google ログインの戻りの処理より前に、Drive の戻りを見る（Review Focus 4 の決め方）。Drive の戻りだったら、Google ログインの戻りの処理はしない。`ctx` に `driveExport`（`createDriveExport` の返り値。無ければ `null`）と、Drive の戻りの知らせ（結果の画面・履歴の画面で 1 回だけ出す）を渡す。
- `history.js`（結果の画面だけ。一覧は変えない）: 設計書 5 章のボタンと知らせ。
  - 「CSV をダウンロード」: `historyToCsv(h, { bom: true })` を `Blob`（`text/csv;charset=utf-8`）にして、`a[download]` を押す形で保存する。使い終わった URL は `URL.revokeObjectURL` で捨てる。
  - 「Google ドライブに保存」: `ctx.driveExport.hasToken()` なら `upload`、無ければ `begin(sid)`。
  - 画面を開いたとき、`ctx.driveExport && ctx.driveExport.takePending(sid)` が `true` なら、結果を読みこんだあとに自動で `upload` する。
  - 今ある「この記録を削除」などの動き・文・並びは変えない。画面を離れたあとに終わった保存の結果は、画面に出さない（`alive` の考え方）。
- テスト: 画面の動きは、今ある画面のテストのやり方（`tests/teacher-admin.test.js`・`tests/google-login.test.js` で画面をどう試しているか）に合わせて、できる範囲で足す。
