## 直すもの

1. **やり直すと、変わった所とちがうスライドが出る。** 履歴の 1 回ぶんに、「変える前の教材と選択」と「変えた後の教材と選択」の両方を持たせる。元に戻す → 変える前の教材と選択へ。やり直す → 変えた後の教材と選択へ。元に戻す・やり直すを押したときに見ていた場所で、覚えた選択を上書きしない。まとめ（1 秒以内の同じ鍵）のときは、「変えた後」だけを新しくする。
2. **別のスライドを見ている間に画像の読みこみが終わったとき。** その 1 回ぶんの選択は、画像を足したスライド（変える前: そのスライド・選択なし。変えた後: そのスライド・足した画像）にする。元に戻す・やり直すで、そのスライドが出る。読みこみが終わった時点では、今見ているスライドは変えない（今のまま）。

`history.js` の形（`record` の引数など）は、必要なら変えてよい。`limit`・`groupMs`・`canUndo`・`canRedo`・`breakGroup`・`clear` の意味は変えない。

## 端の場合

| 場合 | 動き | テスト |
|---|---|---|
| A を編集 → B へ移動 → 元に戻す → やり直す | 元に戻すで A（変える前の選択）、やり直すで A（変えた後の選択） | 自動 |
| 同じスライドの中で、要素 X を変える → 要素 Y を選ぶ → 元に戻す → やり直す | どちらも X を選ぶ | 自動 |
| スライドを足す → 元に戻す → やり直す | 元に戻すで足す前のスライド、やり直すで足したスライド | 自動 |
| スライドを消す → 元に戻す → やり直す | 元に戻すで消したスライド、やり直すで消した後に選ばれたスライド | 自動 |
| 要素を消す → 元に戻す | 消した要素を選ぶ | 自動 |
| 覚えた選択が、戻した教材に無い（不正な値・`null`） | 今までどおり近いスライド、要素の選択は外す。例外にしない | 自動 |
| まとめた入力（3 文字）→ 元に戻す → やり直す | 1 回で空へ、1 回で 3 文字へ | 自動 |
| 50 回をこえる・境界 | 今までどおり | 今あるテスト |
| A で画像の読みこみ開始 → B へ → 読みこみ終わり → 元に戻す → やり直す | 終わった時点は B のまま。元に戻すで A（画像なし）、やり直すで A（画像を選ぶ） | 自動 |
| 画像の読みこみ中に、A が消えた | 今の「足せませんでした」の文。履歴に積まない | 自動 |
| 失敗の見せ方 | 新しい失敗の文は無い | — |
