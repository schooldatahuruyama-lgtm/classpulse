# 実装指示書: 利用を停止した先生の自動削除

**設計書（全部読むこと。これが正）:** `docs/superpowers/specs/2026-11-14-teacher-auto-delete-design.md`
**関係する設計書:** `docs/superpowers/specs/2026-11-15-teacher-delete-design.md`（`repo.deleteTeacher` と規則）

## 守ること

- git の操作はしない。パッケージを足さない。秘密の値を足さない。
- 変えてよい所: `js/repo.js`、`js/config.js`、`js/views/teachers.js`、`js/views/dashboard.js`、`js/main.js`（要るときだけ）、`js/dev/memory-net.js`（要るときだけ）、新しい `js/teacher-cleanup.js`（DOM に触れない）、`css/`、`docs/firebase/rules.json`（設計書 3 章の 2 行だけ。1 文字もちがえない。ほかは変えない）、`tests/`。ほかを変える必要が出たら、変えずに報告に書く。
- `repo.deleteTeacher` の中身（消すもの・確かめ）は変えない。使うだけ。
- 文言は設計書のとおり（やさしい日本語）。

## 作るもの

1. `js/config.js`: `CONFIG.teacher = { deleteDays: 30 }`（今ある形に合わせる）。
2. `js/repo.js`
   - `setTeacherActive(targetUid, active)`: 設計書 3 章の 1 回の書きこみ（止める: `suspendedAt` に `net.serverTimestamp()`。再開: `null`）。拒否・失敗したら、今までの書きこみ（`teacherList` だけ）で 1 回だけやり直す。それも失敗したら例外。自分自身は今までどおり例外。
   - `listTeachers()`: それぞれに `suspendedAt`（正の有限の数。そうでなければ `null`）を足す。
   - `serverNow()`: `check/<uid>` にサーバーの時刻を書いて読み、数を返す。数でなければ例外。
   - `markSuspended(targetUid)`: `teacherDirectory/<targetUid>/suspendedAt` にサーバーの時刻を書く（記録の無い停止中の先生用）。
   - `deleteIfStillSuspended(targetUid, suspendedAt)`: `teacherList/<uid>` と `teacherDirectory/<uid>/suspendedAt` を読み直し、`false` で、同じ時刻のときだけ `deleteTeacher`。消したら `true`、消さなかったら `false`。
3. `js/teacher-cleanup.js`（新規。DOM に触れない）
   - `isDue(suspendedAt, now, days)`、`deleteDate(suspendedAt, days)`、`daysLeft(suspendedAt, now, days)`、`deleteNote(suspendedAt, now, days)`（カードの文。記録なしは `null`）。
   - `runTeacherCleanup({ repo, uid, days })` → `{ deleted: 数 }`。設計書 5 章の手順。管理者でなければ何もしない。どこで失敗しても例外を外へ出さず、消せた人数を返す。同じ `repo`（または同じタブ）で前の回が動いている間は、新しく始めずに `{ deleted: 0 }` を返す。
4. `js/views/dashboard.js` と `js/views/teachers.js`: 開いたときに `runTeacherCleanup` を 1 回（画面の表示を待たせない）。1 人以上消したら、設計書のトースト。「先生の管理」は、一覧を読みこみ直す。画面を離れていたら、何も出さない。
5. `js/views/teachers.js`: カードの文、停止の確認の文（設計書 2 章）。
6. `docs/firebase/rules.json` と `tests/rules.test.js`: 設計書 3 章の 2 行。

## 端の場合（設計書 6 章の表のとおり。全部にテストか、報告での確かめを付ける）

| 場合 | 動き | テスト |
|---|---|---|
| 不正な入力: `suspendedAt` が文字・数字の文字列・負・0・`NaN`・とても大きい値・サーバーの今より先 | 記録なしとして扱い、今の時刻で書き直す。消さない | 自動 |
| 境界: ちょうど 30 日・1 ミリ秒前・31 日 | 消す／消さない／消す | 自動 |
| 範囲外: `days` が 0・負・数でない | 30 として扱う（すぐ消さない） | 自動 |
| 重複: 2 回続けて開いた・2 つのタブ・2 人の管理者 | 2 回目は始めない／片方は「もう無い」で `false`。何も出さない | 自動 |
| 自分自身・利用中・承認待ち・名簿に行が無い停止中 | 消さない。名簿に行が無い先生には `markSuspended` を呼ばない | 自動 |
| 消す直前に再開されていた・止め直されていた（時刻がちがう） | 消さない | 自動 |
| 1 人目が失敗、2 人目は成功 | `deleted: 1` | 自動 |
| 管理者でない・`serverNow` が失敗・一覧の読みこみが失敗・規則が古い（`markSuspended` が拒否） | 何も消さない。例外を出さない | 自動 |
| 止める・再開: 時刻つきの書きこみが拒否 | 今までの書きこみでやり直して成功。両方失敗なら例外（今の失敗の文が出る） | 自動 |
| 見せ方: あと 12 日・今日・過ぎている・記録なし | 設計書 2 章の文／「まもなく…」／「まもなく…」／何も出さない | 自動 |
| 見せ方: 消した人数 0・1・10 | 出さない／1 人／10 人を 1 回だけ | 自動 |
| 違反や失敗の見せ方 | 自動の削除の失敗は出さない。停止・再開の失敗は今の文 | 自動 |
