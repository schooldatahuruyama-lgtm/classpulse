# Codex 実装報告

## 変更したファイル

- `js/zip-read.js`：ZIP の読み取り、CRC 検査、展開量の制限、中止処理を追加。
- `js/xml-read.js`：DOM を使わない XML 読み取りを追加。DOCTYPE・不正な実体・深すぎる入れ子を拒否。
- `js/pptx-import-logic.js`：文字・画像の抽出、座標変換、継承、件数集計、教材の組み立て、案内文を追加。
- `js/pptx-import.js`：端末内での画像変換、進捗通知、中止処理を追加。
- `js/config.js`：設計書の取りこみ上限を追加。
- `js/views/dashboard.js`：PowerPoint ボタン、排他制御、保存、結果表示を追加。
- `css/app.css`：PowerPoint 用ファイル入力のスタイルを追加。
- `tests/helpers/pptx-fixture.js`：テスト内で ZIP・PPTX を組み立てる関数を追加。
- `tests/zip-read.test.js`：破損・暗号化・展開上限などを検証。
- `tests/xml-read.test.js`：XML の正常系・不正入力・深さ制限を検証。
- `tests/pptx-import-logic.test.js`：抽出、配置、画像変換、ホーム連携、中止後に保存・表示しないことを検証。

既存テストの変更はありません。

## 指示書と違う点・判断したこと・残った問題

- 指示範囲外の変更、パッケージ追加、コミットはありません。
- **同じ画像は共有**します。既存の削除処理が他の要素からの参照を確認するため、安全に容量を抑えられます。画像の容量配分は重複を除いた画像数で計算します。
- 結果を読み切れるよう、保存後のまとめはダイアログで表示します。「教材を開く」で編集画面へ進めます。

- 表示対象が 0 枚のファイルは「読めない」扱いとしました。
- 描画モジュールへの依存を避けるため、文字サイズと色の定数を読み取り側にも定義し、表示側との一致をテストしています。
