## 作るもの

1. `js/animation.js`（新規。DOM に触れない）
   - `MAX_STEP = 20`、`normalizeStep(value)` → 0〜20 の整数。
   - `stepCount(slide)` → 資料スライドの出す回数（つめた後）。資料スライドでなければ 0。
   - `itemRank(slide, item)` → その要素が出る回（0 = 最初から。つめた後）。
   - `isItemVisible(slide, item, step)` → `step` が数でなければ `true`（全部出す）。
   - `clampStep(slide, step)` → 0〜`stepCount` の整数。
   - `advance({ order, slides, slideId, step }, dir)` → 次の `{ slideId, step, moved }`（`moved` はスライドが変わったか）。設計書 4 章のとおり。端では今の進み方と同じ結果になること。
2. `js/model.js`: 読みこみ（`normalizeSlide`）で要素の `step` を正す。0 のときは `step` を持たせなくてよい（保存を小さく）。
3. `js/session-host.js`: 「次へ」「前へ」を `advance` で決め、`pub.current.step` を書く。スライドが変わらないときは、質問の締め切りなどの今の処理を起こさない。
4. `js/slide-render.js`: `renderSlide(..., { step })` を足す（渡さなければ今までどおり全部出す）。隠す要素は、作ったうえで見えなくする（あとから出すときにフェードできるように）か、描き直すかは、まかせる。ただし「同じスライド・同じ回数の描き直しではフェードしない」「回数が増えたときに、新しく出る要素だけフェードする」を守る。
5. `js/views/present.js`: 資料スライドを今の回数で描く。「出す 1／3」。スライドが変わったときの切り替え効果。
6. `js/views/student.js`・`js/session-client.js`: `pub.current.step` を受け取り、資料スライドを今の回数で描く。参加・つなぎ直しのときはフェードなし。
7. 編集画面: 設定の「出る順番」（「−」「＋」、`ed.updateItem` で保存。まとめの鍵 `step`）、キャンバスの番号の印。
8. `css/`: フェード（0.3 秒）、切り替え効果（0.25 秒）、番号の印、`prefers-reduced-motion`。

## 端の場合（設計書 6 章の表のとおり。全部にテストか、報告での確かめを付ける）

| 場合 | 動き | テスト |
|---|---|---|
| 不正な入力: `step` が文字・数字の文字列 `"3"`・小数 `2.7`・負・`21`・とても大きい値・`NaN`・`null` | 0／0／2／0／20／20／0／0 | 自動 |
| 不正な入力: `pub.current.step` が無い・文字・負・回数より大きい | 生徒は全部出す／全部出す／0／回数 | 自動 |
| 境界: 「＋」を 20 で、「−」を 0 で | 止まる。`disabled` | 自動 |
| 重複ととび: 同じ番号 2 つ、1 と 3 だけ | いっしょに出る／2 回 | 自動 |
| 順番のある要素が 0 個・全部に順番 | 今までと同じ／白いスライドから | 自動 |
| 「次へ」: 途中・最後の回・最後のスライドの途中・最後のスライドの最後 | 出す／次のスライド（step 0）／出すだけ／今の動き | 自動 |
| 「前へ」: 途中・0 のとき・最初のスライドの 0 | 1 回隠す／前のスライドが全部出た状態／今の動き | 自動 |
| 質問のスライドの締め切り | 同じ資料スライドの中で出すだけなら、何も締め切らない。スライドが変わるときは今のまま | 自動 |
| 同じスライド・同じ回数の描き直し | フェードの印（クラス）を付け直さない | 自動 |
| 途中参加・つなぎ直し・先生の読みこみ直し | 今の回数をフェードなしで | 自動（できる所）＋報告 |
| 違反の見せ方 | 不正な値は黙って正す。新しい失敗の文は無い | 自動 |
